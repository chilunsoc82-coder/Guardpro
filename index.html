// Modules

Mỗi module hoạt động độc lập — bật tắt riêng theo nhu cầu từng server.

Guard & Antinuke

Phát hiện và chặn hành vi phá server: xoá kênh hàng loạt, ban/kick bất thường, webhook lạ.

🚨ONLINE

Anti-raid & Anti-spam

// Commands

Dùng quen tay, gõ là chạy.

Prefix mặc định ! — một số lệnh chính đang được chuyển dần sang slash command /.

!guard onBật toàn bộ hệ thống bảo vệ server
!antinuke setupCấu hình chống nuke, đặt giới hạn hành động
!play [tên bài hát]Phát nhạc trong kênh voice
!balanceXem số dư kinh tế hiện tại
!ticket setupTạo hệ thống ticket hỗ trợ
!serverstatsThống kê tổng quan server
Danh sách đầy đủ: gõ !help trong server đã mời GuardPro.

Privacy Policy

Cập nhật lần cuối: [điền ngày]

1. Dữ liệu chúng tôi thu thập

GuardPro lưu trữ tối thiểu dữ liệu cần thiết để vận hành: ID server, ID người dùng, cấu hình bật/tắt tính năng, dữ liệu kinh tế/level nội bộ, danh sách whitelist/blacklist do quản trị viên thiết lập.

2. Nội dung tin nhắn

Bot đọc nội dung tin nhắn để phục vụ các tính năng antilink, autoresponder, lọc từ cấm. Nội dung tin nhắn không được lưu trữ lâu dài trừ khi cần thiết cho log kiểm duyệt.

3. Chia sẻ dữ liệu

Chúng tôi không bán hoặc chia sẻ dữ liệu người dùng cho bên thứ ba ngoài mục đích vận hành bot.

4. Quyền của bạn

Quản trị viên server có thể yêu cầu xoá toàn bộ dữ liệu liên quan đến server bằng cách liên hệ qua Support Server.
